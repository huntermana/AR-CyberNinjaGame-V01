# ⚡ Cyber Ninja: Firewall Slasher (ไซเบอร์นินจา ผ่ามัลแวร์กู้เซิร์ฟเวอร์)

> **Web AR Motion & Hand-Tracking Game สำหรับค่าย ICT และวิทยาการคำนวณ**  
> พัฒนาด้วย Google MediaPipe Hands (CDN), HTML5 Canvas 2D/WebGL, และ Web Audio API

---

## 🎮 1. ภาพรวมและจุดเด่นของเกม (Highlights)
- **ไม่ต้องติดตั้งแอป (Zero-Install Web AR):** ใช้งานผ่านเว็บเบราว์เซอร์ (Chrome / Edge / Safari) บน iPad, แท็บเล็ต Android หรือคอมพิวเตอร์แล็ปท็อป
- **ระบบตรวจจับมือเรียลไทม์ (30+ FPS):** ใช้ Google MediaPipe Hands ตรวจจับพิกัด 21 จุดข้อมือและปลายนิ้ว พร้อมเอฟเฟกต์ **Cyber Blade Trail** ลำแสงนีออนเคลื่อนไหวตามมือ
- **3 ท่าไม้ตายควบคุมเกม:**
  1. **ฟัน / ฟาดมือ (Slash / Chop):** ตวัดมือผ่ามัลแวร์ (โทรจัน, แรนซัมแวร์, ฟิชชิ่ง, สปายแวร์, เวิร์ม, บ็อตเน็ต)
  2. **แบมือรับ (Catch / Hold):** กางฝ่ามือประคองรับข้อมูลปลอดภัย (กุญแจ SSL, โล่ไฟร์วอลล์, ไฟล์สำรอง) เข้าสู่เซิร์ฟเวอร์ *(หากเผลอฟันจะถูกหักแต้ม!)*
  3. **ชูมือตอบคำถาม (Floating Choice):** ชูมือหรือฟันแตะตัวเลือกเหตุการณ์ความปลอดภัยไซเบอร์ A หรือ B กลางอากาศ
- **3 โหมดการเล่นสุดมันส์:**
  - **โหมด 1: Team Score Attack:** เล่นเดี่ยว 60 วินาที สะสมแต้มเข้าสู่ทีม พร้อมระบบ Combo Overdrive
  - **โหมด 2: 1v1 Split Duel:** ประลองนินจาคู่ จอแบ่งซ้าย (ทีมฟ้า) - ขวา (ทีมแดง) ตรวจจับมือแยกฝั่งอิสระ มีระบบ Freeze Frame และแบนเนอร์ยักษ์ฉายขึ้นจอ TV
  - **โหมด 3: Co-op Firewall Relay:** วิ่งผลัดทีม 4-8 คน สลับหน้ากล้องทุก 15 วิ สกัดกั้นการโจมตี DDoS และเก็บกุญแจ SSL ครบ 10 ดอก
- **รองรับสองภาษา (Bilingual):** สลับภาษาไทย 🇹🇭 (Default) และภาษาอังกฤษ 🇬🇧 ได้ทุกหน้าจอ
- **โหมดถ่ายทอดออกจอทีวี (TV Broadcast Mode):** ขยายขนาดตัวเลข ตัวหนังสือ และขอบเขตเซนเซอร์ให้เห็นชัดเจนจากระยะไกลในห้องจัดกิจกรรม

## 🚀 2. วิธีการเปิดใช้งานเกม (Quick Start)

### วิธีที่ 1: รันด้วย Python (แนะนำ สะดวกที่สุด)
เปิด Terminal / PowerShell ในโฟลเดอร์โครงการ แล้วพิมพ์คำสั่ง:
```bash
python -m http.server 8000
```
จากนั้นเปิดเว็บเบราว์เซอร์ไปที่: `http://localhost:8000` (หรือเปิดผ่าน IP เครื่องบนแท็บเล็ตในวง Wi-Fi เดียวกัน)

### วิธีที่ 2: รันด้วย Node.js
```bash
npx serve .
```

## 📷 3. คำแนะนำการติดตั้งฮาร์ดแวร์ในฐานกิจกรรมค่าย (Hardware Setup)
1. **การวางแท็บเล็ต/แล็ปท็อป:**
   - วางบนขาตั้งโต๊ะ (Stand) ความสูงระดับหน้าอกของผู้เล่น
   - หันกล้องหน้า (Front Camera) สู่ผู้เล่นในระยะ **1.2 – 1.8 เมตร**
   - ระบบจะทำการ Mirror สตรีมภาพให้ผู้เล่นขยับมือเหมือนส่องกระจกเงาโดยอัตโนมัติ
2. **สภาพแสงในห้อง:**
   - ควรมีแสงสว่างสม่ำเสมอ หลีกเลี่ยงแสงส่องย้อนหลังผู้เล่น (Backlight) เพื่อให้ MediaPipe จับข้อต่อนิ้วมือได้แม่นยำที่สุด
3. **การฉายภาพขึ้นจอใหญ่:**
   - ต่อสาย HDMI หรือ Cast หน้าจอไปยัง Smart TV / Projector ในห้องกิจกรรม
   - กดปุ่ม `📺 จอ TV / Projector` ที่มุมบนขวา เพื่อเปิดโหมด **TV Broadcast Mode** (ตัวหนังสือและป้ายคะแนนจะขยายใหญ่ 1.35 เท่า)

## 🖱️ 4. โหมดจำลองเมาส์ / สัมผัส (Simulator Fallback)
หากอยู่ในห้องที่ยังไม่ได้เสียบกล้อง หรือต้องการทดสอบระบบโดยไม่ต้องเปิดกล้อง:
- กดปุ่ม **`🖱️ สลับโหมด เมาส์/กล้อง`** ที่แถบเมนูด้านบน
- เลื่อนเมาส์ไปมาเพื่อควบคุมดาบเลเซอร์ไซเบอร์
- กด **Spacebar** หรือ **คลิกเมาส์ค้าง** เพื่อเปิดท่า "แบมือรับข้อมูลปลอดภัย (Open Palm)"

---

## 🏆 5. การจัดการคะแนนและส่งออกข้อมูล (Leaderboard & Export)
- คะแนนในโหมด Team Score Attack จะถูกบันทึกแยกตามทีม (Alpha, Beta, Gamma, Delta)
- ครูผู้สอนสามารถกดปุ่ม **`📥 ส่งออกข้อมูล (CSV)`** เพื่อดาวน์โหลดสรุปคะแนนนักเรียนเป็นไฟล์ Excel / CSV ไปประกาศรางวัลท้ายค่ายได้ทันที
- มีปุ่ม **`🗑️ ล้างคะแนนทั้งหมด`** พร้อมระบบยืนยัน สำหรับเริ่มรอบค่ายใหม่
